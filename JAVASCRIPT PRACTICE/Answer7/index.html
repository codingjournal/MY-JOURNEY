Q7. What are Number Variables and String Variables. Show output using console?

Answer:
Number Variables are those variables which stores Numbers.
Below Code is to be written in Javascript file and Right Click on the Page and select inspect and then go to console tab for seeing the output.

let age = 34;
console.log(age);

String Variables are those variable which stores String.Value of String variable are enclosed within double brackets.

let name = "Johny Singh";
console.log(name);
